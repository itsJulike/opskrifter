# Opskrifter (offentlige data)

Opskrifterne til https://markusvej.dk/opskrifter. Appens kode ligger i `itsJulike/hunde` (mappen
`opskrifter/`), og vejledningen står i `opskrifter/LÆS MIG.md` der.

- `recipes.json` – opskrifterne
- `billeder/` – billeder til opskrifterne

Repoet er offentligt, så alle kan se opskrifterne uden login, fx når en opskrift bliver delt. Kun en
GitHub-nøgle med adgang til repoet kan ændre dem. Appen gemmer her, når du er logget ind.

Madplanen ligger stadig i det private repo `itsJulike/opskrifter-data`.

**Backup:** Hele historikken ligger i GitHub. Åbn `recipes.json`, tryk på *History* og hent en ældre
udgave. Historikken fra før opskrifterne blev flyttet hertil ligger i `itsJulike/opskrifter-data`.
